## Описание предметной области

Система предназначена для автоматизации работы сети барбершопов.
База данных хранит сведения о филиалах сети, мастерах и их графике
работы, клиентах, предварительных записях и фактически оказанных
услугах.

Основные сценарии использования: запись клиента к конкретному мастеру
на свободное время, учёт оказанных за визит услуг и их стоимости по
прайсу филиала, учёт расходных материалов и поставок, сбор отзывов
клиентов, а также получение аналитики по загрузке мастеров и выручке
филиалов.

## Основные сущности

Филиал, Мастер, Смена, Клиент, Запись, Визит, Услуга, Прайс,
Расходный материал, Поставщик, Поставка, Отзыв.

## Структура репозитория

- `schemas/` — концептуальная, логическая и физическая схемы БД
- `data/` — данные для загрузки в базу в формате CSV
- `base_part/` — SQL-скрипты обязательных этапов
- `advanced_part/` — материалы дополнительных этапов
